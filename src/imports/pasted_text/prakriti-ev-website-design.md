# DESIGN A PREMIUM MODERN WEBSITE FOR PRAKRITI EV

## ROLE

Act as a world-class senior UI/UX designer, creative web designer, design strategist and automotive technology website specialist.

Design a complete, production-quality website concept for **Prakriti EV**, an Indian electric vehicle / electric scooter company.

This is a **high-fidelity Figma demo/prototype**, not a direct copy of the existing website.

Use the existing Prakriti EV website as the information and business reference, but completely modernize the visual language, layout, interaction patterns and storytelling.

Reference website:
https://prakritiev.in/

The final design should feel like a premium combination of:

* Modern EV technology
* Indian automotive brand
* Clean corporate website
* Premium product showcase
* Minimal editorial design
* Futuristic mobility
* Trustworthy manufacturing company
* High-conversion commercial website

DO NOT make it look like a generic startup landing page.

DO NOT copy the existing website's visual design.

Instead, retain its important content architecture and improve the experience dramatically.

Create a visual identity based on:

**"Modern Indian Mobility. Designed for Tomorrow."**

The website should communicate:

* Technology
* Reliability
* Performance

* Indian manufacturing
* Innovation
* Affordability
* Everyday usability
* Premium engineering

Visual style:

Minimal + sophisticated + technical + automotive.

Think of the design language as a blend of:

* Premium automotive websites
* Modern EV brands
* Technology companies
* High-end industrial design
* Contemporary Indian corporate branding

Avoid excessive gradients.

Avoid excessive glassmorphism.

Avoid overly rounded "SaaS startup" cards.

Avoid clutter.

Avoid childish illustrations.

Avoid excessive green eco clichés.

The website should feel **confident, engineered and premium**.
